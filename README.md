# Linear and Circular Interpolation of Industrial Manipulator

## Aim

To understand the **linear and circular interpolation** of an industrial manipulator and develop a suitable robot program for performing these motions.

---

## Apparatus Required

1. Industrial Robotic Manipulator
2. Robot Controller
3. Teach Pendant
4. Computer with Robot Programming/Simulation Software
5. End-Effector / Gripper
6. Work Table or Suitable Workspace
7. Power Supply and Connecting Cables

---

## Theory

### Linear Interpolation

Linear interpolation is a robot motion in which the end-effector moves from one taught point to another along a **straight-line path**.

For example:

```text
P1 ------------------------> P2
       Straight Line
```
